# Vero

Your team's work, in one place: boards, notes, chat, calls and a calendar, organised by project and module.

- `code/` — the application: `apps/` (web, desktop, shared UI), `services/` (seven backend services), `packages/shared/`, `ai-worker/`, `infra/`
- `doc/` — reports, diagrams and planning notes

See `code/scripts/dev-stack.sh` to run the full stack locally.
